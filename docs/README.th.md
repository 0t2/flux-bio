**TL;DR**

- หน้า Link in bio และลิงก์สั้นพร้อมสถิติการคลิก ในเครื่องมือเดียว
- ทำงานบนบัญชี Cloudflare ของคุณเอง แพ็กเกจฟรีก็พอ และข้อมูลยังเป็นของคุณ
- [วางข้อความเดียวให้ AI ของคุณ](#ติดตั้งเอง) แล้ว AI จะติดตั้งให้ทั้งหมด จากนั้นแก้ไขในแดชบอร์ด หรือบอก AI ได้เลย

สร้างหน้า bio ในสไตล์ของคุณได้หลายหน้า: เลือกธีมและชุดสี หรือให้ AI ทำธีมจากรูปของคุณ ใส่วิดีโอ สินค้า และเวลาทำการได้ด้วย ทุกลิงก์บนหน้ามีลิงก์สั้นด้วย และเห็นได้ว่าคนคลิกอะไร และมาจาก IG, Threads หรือ LINE

## ฟีเจอร์

### ให้ AI ดูแล

- สร้าง API token ในหน้าการตั้งค่า แล้ววางพรอมต์บนหน้าจอลงใน Claude Code, Codex หรือ Cursor จากนั้นแค่บอกให้แก้หน้า สร้างลิงก์สั้น ดูสถิติ หรือเปลี่ยนโดเมนและเขตเวลา
- ทุกชุดที่ดีพลอยมาพร้อมคู่มือสำหรับ AI (`/llms.txt`, `/skill.md`) และข้อกำหนด API (`/api/openapi.json`) ก่อนเผยแพร่ ลบ หรือเปลี่ยน URL AI จะเตือนความเสี่ยงให้ก่อน และยังช่วยแนะนำได้ด้วย

### หน้า bio

- FluxBio ชุดเดียวดูแลได้หลายหน้า แต่ละหน้ามี URL ธีม และสถิติของตัวเอง
- 24 ธีม แต่ละธีมมีเลย์เอาต์ของตัวเองและชุดสีหลายชุด: นีออน พาโนรามา ช่องสี ลูกอม โปร่ง ออโรรา การ์ด ฝ้า อาทิตย์ตก ท้องฟ้า ป๊อป ภาพเหมือน แผ่น ราง สองสี นูน เบนโตะ จุด พาสเทล จดหมาย ออบซิเดียน จันทร์ ชิป และแทร็ก
- ต้องการแค่ลิงก์สั้น? ปิดฟีเจอร์หน้าได้ในแดชบอร์ด หน้าสาธารณะจะออฟไลน์ ลิงก์สั้นยังใช้งานได้ และไม่มีข้อมูลใดถูกลบ
- ไม่อยากใช้หน้าลิงก์หรือ หน้าใดก็เปลี่ยนเป็น HTML ของคุณเองหรือเปลี่ยนเส้นทางไปที่อื่นได้ และใช้เป็นหน้าแรกได้ทั้งคู่
- ฟอนต์: ฟอนต์ของแต่ละธีมโหลดจาก Google Fonts โดยไม่ใช้โควตาของคุณ เปิดสวิตช์ในหน้ารูปลักษณ์เพื่อส่งจาก Worker ของคุณเองแทน ผู้เข้าชมจะไม่เชื่อมต่อกับ Google (เหมาะเมื่อมีผู้เข้าชมจาก EU) ส่วนฟอนต์อื่นจาก Google Fonts ให้บอก AI ของคุณ ดูการใช้โควตาได้ในคำถามที่พบบ่อย
- ธีมของคุณเอง: ให้ AI ทำธีมจากสี ฟอนต์ รูปปก และพื้นหลังของคุณ ส่วน[ไฟล์ธีม](../themes/)ที่คนอื่นแชร์มา ก็ให้ AI ใส่ให้ได้เลย
- บล็อกเนื้อหา: ลิงก์ หัวข้อ วิดีโอ (YouTube / Vimeo) สไลด์รูปภาพ การ์ดสินค้า เวลาทำการและแผนที่
- ตั้งลิงก์เป็นไฮไลต์ ซ่อน หรือตั้งเวลาเริ่มและหยุดแสดงได้
- เทมเพลต: ครีเอเตอร์ ร้านค้า อีเวนต์ มืออาชีพ องค์กร เริ่มได้ในคลิกเดียว
- ภาพพรีวิวเวลาแชร์ลง LINE หรือ Facebook สร้างให้อัตโนมัติตามธีม รูปนี้สร้างตอนเผยแพร่จากแดชบอร์ด หรือให้ AI ใช้ภาพหน้าจอของหน้าแทนก็ได้
- วางปุ่ม LINE ที่มุมขวาล่างได้ ผู้เข้าชมแตะครั้งเดียวก็เพิ่มเพื่อนได้

### ลิงก์สั้น

- ทุกลิงก์บนหน้า bio จะกลายเป็นลิงก์สั้นอัตโนมัติเมื่อเผยแพร่ หรือจะสร้างแยกก็ได้ ส่วนการสร้างทีละหลายลิงก์พร้อม UTM แยกตามแพลตฟอร์ม ให้ AI ทำ ปุ่มบนหน้าจะแสดงที่อยู่จริง สวิตช์เดียวเปลี่ยนเป็นลิงก์สั้นได้ สำหรับลิงก์ที่ไม่อยากเปิดเผย เช่น ลิงก์แอฟฟิลิเอต
- ชื่อย่อใช้ตัวอักษรภาษาไหนก็ได้ รวมถึงภาษาไทยและภาษาฮินดี
- QR Code เปลี่ยนสี รูปทรงจุด ไอคอนตรงกลาง และข้อความในกรอบได้ ดาวน์โหลดเป็น PNG / SVG / PDF
- เวลาเปิดใช้ วันหมดอายุ ป้องกันด้วยรหัสผ่าน และ UTM
- เปลี่ยนเส้นทางอัจฉริยะ: เปิดด้วยเบราว์เซอร์ภายนอกเมื่ออยู่ใน LINE แนะนำให้เปิดเบราว์เซอร์ภายนอกก่อนเมื่อเปิดจากเบราว์เซอร์ในแอป IG / FB และส่ง iPhone กับ Android ไปคนละปลายทางได้

### สถิติ

- การเข้าชม คลิก อัตราการคลิก และแหล่งที่มา: นับแม่นยำ (D1) เก็บรายวัน 13 เดือน หลังจากนั้นเก็บเป็นรายเดือน
- ผู้เข้าชมไม่ซ้ำ พื้นที่ แผนที่ผู้เข้าชม ผู้ให้บริการเครือข่าย อุปกรณ์ เบราว์เซอร์ ภาษา เว็บไซต์ภายนอก UTM ช่วงเวลาที่คลิก และกิจกรรมล่าสุด: เก็บ 90 วัน (Cloudflare Analytics Engine ไม่ต้องตั้งค่า)
- เทียบกับช่วงก่อนหน้า มีหน้าสถิติของลิงก์สั้นแต่ละลิงก์ และส่งออก CSV ได้
- ไม่ใช้คุกกี้ ไม่เก็บ IP ไม่เก็บสตริง User-Agent แบบเต็ม และเก็บตำแหน่งแค่ระดับเมือง ID ผู้เข้าชมเป็นแฮชทางเดียวที่เปลี่ยนทุกวัน และไม่นับบอต

### ภาษาและการติดตั้ง

- **13 ภาษา**: ทั้งแดชบอร์ดและหน้าสาธารณะมี 繁體中文, 简体中文, English, 日本語, 한국어, Español, Português, Français, Deutsch, Bahasa Indonesia, ไทย, Tiếng Việt และ العربية หน้าสาธารณะใช้ภาษาเดียวที่คุณเลือก และเปิดภาษาอื่นเพิ่มได้ ผู้เข้าชมที่เบราว์เซอร์ใช้ภาษานั้นจะสลับให้อัตโนมัติ AI ของคุณแปลข้อความที่คุณเขียนเองเป็นภาษาเหล่านั้นได้ด้วย
- **หน้าสาธารณะแทบไม่มี JavaScript**: เป็น HTML ล้วนที่ส่งออกจาก edge ของ Cloudflare โดยตรง จึงเร็วมาก มีเพียงสคริปต์เล็ก ๆ ตัวเดียวที่นับคลิก และหน้าใช้งานได้แม้ไม่มีมัน วิดีโอและแผนที่จะโหลดเมื่อผู้เข้าชมแตะเท่านั้น
- **ติดตั้งเอง**: ใช้แค่ Workers, D1, KV และ Analytics Engine ของ Cloudflare ซึ่งไม่ต้องตั้งค่าเองเลยสักอย่าง และไม่ต้องสมัครบริการอื่นเพิ่ม (ฟอนต์โหลดจาก Google Fonts เป็นค่าเริ่มต้น และปิดได้) ให้ AI ส่งออกและนำเข้าเนื้อหาทั้งหมดในครั้งเดียว ก็สำรองข้อมูลหรือย้ายไปอีกชุดได้
- **หลายไซต์ในการติดตั้งครั้งเดียว**: โดเมนสองโดเมนเป็นสองไซต์ที่แยกจากกันใน FluxBio ชุดเดียวกันได้ เช่น หน้าเพจอยู่ที่โดเมนหนึ่ง และลิงก์สั้นอยู่อีกโดเมนหนึ่ง แต่ละไซต์มีหน้าเพจ ลิงก์สั้น และสถิติของตัวเอง สลับไปมาได้จากเมนูมุมซ้ายบนของแดชบอร์ด การเพิ่มไซต์ต้องให้ AI ของคุณทำ เพิ่มเองจากแดชบอร์ดไม่ได้

## ติดตั้งเอง

AI จะติดตั้งเครื่องมือที่ต้องใช้ให้ แค่ลองใช้มีเพียง Claude Code ก็พอ ส่วนตอนนำขึ้นออนไลน์จึงต้องมีบัญชี Cloudflare ฟรี หากทำเอง ต้องมี Node.js 22.23+, 24.22+ หรือ 26.12+ และ pnpm

### ง่ายที่สุด: ให้ AI ทำ

วางให้ AI ของคุณ เราแนะนำ [Claude Code](https://code.claude.com/docs/en/quickstart) บนคอมพิวเตอร์ของคุณเอง แต่ Codex, OpenCode, Cursor และตัวอื่นที่รันคำสั่งและต่ออินเทอร์เน็ตได้ก็ใช้ได้:

```text
ช่วยให้ฉันลองใช้ FluxBio ก่อนอื่นให้รันคำสั่งนี้เพื่อดาวน์โหลดมาไว้ในคอมพิวเตอร์เครื่องนี้:

mkdir -p ~/flux-bio && curl -fsSL https://github.com/0t2/flux-bio/archive/refs/heads/main.tar.gz | tar -xz --strip-components=1 -C ~/flux-bio

จากนั้นอ่าน ~/flux-bio/AGENTS.md ให้จบทั้งไฟล์ แล้วทำตามหัวข้อที่ 1 ให้อ่านจากไฟล์ในโฟลเดอร์นั้น ไม่ใช่จากเว็บ ถ้าดาวน์โหลดไม่สำเร็จ ให้หยุดแล้วบอกฉัน
ใช้ภาษาไทย (th) เป็นภาษาของหน้า
```

AI จะถามก่อนว่าอยากดูหน้าตัวอย่างบนคอมพิวเตอร์ของคุณไหม โดยไม่ต้องมีบัญชี เมื่อพอใจแล้วจึงให้คุณเข้าสู่ระบบ Cloudflare นำขึ้นออนไลน์ และเชื่อมต่อตัวเองเข้ามาดูแลให้ คุณเป็นคนตัดสินใจว่าจะเผยแพร่เมื่อไร หลังจากนั้นอยากแก้อะไรก็แค่บอก ChatGPT และ Claude บนเบราว์เซอร์ทำไม่ได้ เพราะรันอะไรบนคอมพิวเตอร์ของคุณไม่ได้

> [!NOTE]
> ระหว่างทางจะมีการขออนุญาตสองสามครั้ง AI จะถามก่อนรันคำสั่ง (ดาวน์โหลดโค้ด ติดตั้งแพ็กเกจ ดีพลอย) Cloudflare จะให้คุณกดอนุมัติการเข้าสู่ระบบในเบราว์เซอร์ และ AI จะถามอีกครั้งก่อนบันทึกโทเค็นลงในคอมพิวเตอร์ของคุณ ดูให้แน่ใจว่าแต่ละขั้นทำอะไรแล้วค่อยอนุญาต

### ทำเอง

```sh
git clone https://github.com/0t2/flux-bio.git
cd flux-bio
pnpm install
pnpm exec cf auth login          # ครั้งแรกต้องเข้าสู่ระบบ Cloudflare

# สร้างรหัสผ่านแดชบอร์ด (ADMIN_PASSWORD อย่างน้อย 12 ตัวอักษร) แล้วดีพลอย
printf 'ADMIN_PASSWORD=%s\n' "$(openssl rand -base64 30 | tr -dc 'A-Za-z0-9' | head -c 24)" > .secrets.env
pnpm exec cf deploy --secrets-file .secrets.env
cat .secrets.env && rm .secrets.env   # เก็บรหัสผ่านไว้ให้ดี
```

ดีพลอยเสร็จแล้ว เปิด `https://<เว็บไซต์ของคุณ>/admin/` และเข้าสู่ระบบด้วยรหัสผ่าน การตั้งค่าครั้งแรกจะพาคุณสร้างหน้าแรก แล้วเชื่อมต่อ AI ของคุณใน “ตั้งค่า” หลังจากนั้นเรื่องโดเมน เขตเวลา การสำรองข้อมูล และการเปลี่ยนรหัสผ่าน แค่บอก AI ได้เลย การดีพลอยครั้งแรกจะสร้างฐานข้อมูล D1 และ KV ให้อัตโนมัติ

## ดูว่าผู้เข้าชมมาจากไหน

FluxBio บันทึกว่าการเข้าชมแต่ละครั้งมาจากไหนโดยไม่ใช้คุกกี้ ในหน้า “สถิติ” ส่วน “แพลตฟอร์มต้นทาง” จะแสดงว่ามีกี่คนเปิดหน้า bio ของคุณจากแต่ละแพลตฟอร์ม และคลิกลิงก์ต่อไปกี่ครั้ง ส่วน “แคมเปญ UTM” จะแยกย่อยตามแท็กบนลิงก์ของคุณ

### สิ่งที่ระบบรู้เอง

- **เบราว์เซอร์ในแอป:** Instagram, Threads, Facebook (รวม Messenger), LINE, X, TikTok, WeChat, Weibo, KakaoTalk, NAVER, Zalo, Snapchat, Pinterest และ LinkedIn
- **เว็บไซต์ที่ลิงก์มา:** X (t.co), YouTube, Reddit, เครื่องมือค้นหาอย่าง Google, Bing, Yahoo และ Baidu รวมถึงเว็บไซต์อื่นทุกแห่ง โดยแสดงเป็นชื่อโดเมน
- **QR Code** ที่สร้างใน FluxBio จะมี `?s=qr` ติดไปด้วย
- ลิงก์บนหน้า bio จะส่งต่อแหล่งที่มา ดังนั้นการคลิกจะนับให้แพลตฟอร์มที่ผู้เข้าชมมาจาก

### สิ่งที่ต้องติดแท็กเอง

บางช่องทางไม่บอกว่าผู้เข้าชมมาจากไหน การเข้าชมจึงนับเป็น “เข้าตรง/อื่น ๆ”:

- WhatsApp, Telegram, Discord, iMessage และ SMS
- อีเมล จดหมายข่าว และ PDF
- โปสเตอร์ นามบัตร และสิ่งพิมพ์อื่น ๆ (ใช้ QR Code จาก FluxBio)

เติม `?s=` ตามด้วยชื่อท้ายลิงก์ที่แชร์ เช่น `https://links.example.com/?s=whatsapp` หรือ `https://links.example.com/talk?s=email` สำหรับลิงก์สั้น ใช้ชื่อย่อได้ด้วย เช่น `ig`, `fb`, `x`, `th`, `wa`, `tg`, `mail`, `qr` ถ้าติดแท็ก `?s=` ไว้ ระบบจะใช้แท็กนั้นก่อนการตรวจจับอัตโนมัติ

### หลายตำแหน่งในแพลตฟอร์มเดียว: `utm_content`

ลิงก์ใน bio ของ Instagram สตอรี่ และโพสต์ ล้วนนับเป็น Instagram ถ้าอยากเปรียบเทียบ ให้แต่ละตำแหน่งมีลิงก์ของตัวเอง:

- ใน bio ของ Instagram: `https://links.example.com/?utm_content=bio`
- ในสตอรี่: `https://links.example.com/?utm_content=story`

แต่ละอันจะแยกเป็นแถวของตัวเองใน “แคมเปญ UTM” โดยนับการเข้าชมและการคลิกแยกกัน และผู้เข้าชมจะยังมีแท็กนี้ติดไปเมื่อแตะลิงก์บนหน้าของคุณ ลิงก์สั้นก็ตั้ง `utm_source`, `utm_medium`, `utm_campaign` และ `utm_content` ได้เช่นกัน (หน้า “ลิงก์สั้น” → “ตั้งค่าขั้นสูง”) แท็กเหล่านี้จะต่อท้ายปลายทาง เว็บไซต์ที่คุณลิงก์ไปจึงเห็นด้วย

> [!TIP]
> หรือบอก AI ไปเลยว่า “ช่วยทำลิงก์ติดตามสำหรับ bio ของ Instagram สตอรี่ และโพสต์ให้หน่อย”

### ควรรู้

- คุณเห็นได้ว่าผู้เข้าชมมาจากไหน แต่ไม่เห็นว่าเป็นใคร Instagram, Facebook และ X ไม่เคยบอกเว็บไซต์อื่นว่าบัญชีไหนแตะลิงก์ และ FluxBio ไม่เก็บข้อมูลใดที่ระบุตัวบุคคลได้
- ชื่อใน `?s=` ใช้ได้เฉพาะตัวอักษรภาษาอังกฤษ ตัวเลข `-` และ `_` และจะถูกแปลงเป็นตัวพิมพ์เล็ก ตัวอักษรอื่น (รวมถึงภาษาไทย) จะถูกตัดทิ้ง ส่วนแท็ก UTM จะเก็บตามที่เขียน `story` กับ `Story` จึงนับเป็นสองแถว ควรสะกดให้เหมือนกันทุกครั้ง
- ตำแหน่งคือเมืองที่ Cloudflare ประมาณจาก IP ของผู้เข้าชม คนที่ใช้ VPN, รีเลย์ส่วนตัวของ iCloud หรือเครือข่ายบริษัท อาจแสดงเป็นที่อื่น
- การเข้าชม การคลิก และแหล่งที่มาเป็นตัวเลขที่แม่นยำ ตัวเลขรายวันเก็บไว้ 13 เดือน จากนั้นแต่ละเดือนจะเหลือยอดรวมเดียวและเก็บไว้ตลอด ดาวน์โหลดทั้งหมดได้จากหน้าการตั้งค่า ส่วนพื้นที่ แผนที่ เครือข่าย อุปกรณ์ ภาษา และรายละเอียด UTM เก็บไว้ 90 วัน และการเข้าชมใหม่จะแสดงหลังผ่านไปราวหนึ่งนาที เลือกได้เองว่าจะนับไอคอนโซเชียลด้วยหรือไม่ ปุ่มที่แสดงที่อยู่จริงนับคลิกด้วยสคริปต์เล็ก ๆ บนหน้า ถ้าถูกบล็อกก็อาจนับไม่ได้ ส่วนลิงก์สั้นนับได้เสมอ
- ผู้เข้าชมไม่ซ้ำนับเป็นรายวัน คนเดิมที่มาคนละวัน หรือมาจากมือถือแล้วตามด้วยคอมพิวเตอร์ จะนับเป็นสองครั้ง
- บอตและการพรีวิวลิงก์ (คำขอที่แอปแชตส่งมาเมื่อมีคนวางลิงก์) ไม่ถูกนับ ตัวเลขจึงอาจน้อยกว่าเครื่องมืออื่น
- แท็ก UTM ของลิงก์สั้นจะต่อท้ายเฉพาะปลายทางหลัก ไม่ต่อท้ายลิงก์ที่ตั้งแยกไว้สำหรับ iPhone หรือ Android และจะไม่ทับแท็กที่ปลายทางมีอยู่แล้ว การแก้แท็กมีผลกับการคลิกหลังจากนั้นเท่านั้น
- ระบบรู้จักแอปจากวิธีที่เบราว์เซอร์ในแอประบุตัวเอง ถ้าแอปเปลี่ยนวิธีนี้ การเข้าชมจากแอปนั้นอาจนับเป็น “เข้าตรง/อื่น ๆ” จนกว่า FluxBio จะอัปเดต

<details>
<summary><b>ใช้ฟอนต์อื่นได้ไหม</b></summary>

แต่ละธีมมีฟอนต์ของตัวเอง ถ้าอยากใช้ฟอนต์อื่นจาก Google Fonts ให้บอก AI ของคุณ เช่น "เปลี่ยนหัวข้อเป็น Playfair Display" AI จะหาฟอนต์ อธิบายการใช้โควตา แล้วเผยแพร่หน้าให้ โดยค่าเริ่มต้นฟอนต์จะโหลดจาก Google Fonts ไม่ใช้โควตาของคุณ แต่เบราว์เซอร์ของผู้เข้าชมจะเชื่อมต่อกับ Google ในปี 2022 ศาลเยอรมนีตัดสินว่าตาม GDPR ต้องได้รับความยินยอมจากผู้เข้าชมก่อน ถ้าคุณมีผู้เข้าชมจาก EU ให้เปิด "โหลดฟอนต์จากเว็บไซต์ของคุณเอง" ในหน้ารูปลักษณ์ เมื่อเผยแพร่ ระบบจะคัดลอกเฉพาะตัวอักษรที่หน้าใช้ไปยัง Worker ของคุณเอง และไฟล์ฟอนต์แต่ละไฟล์ใช้ 1 คำขอและการอ่าน KV 1 ครั้งต่อผู้เข้าชมใหม่หนึ่งคน (ฟอนต์ในตัวของหน้ามีอยู่แล้ว 2–3 ไฟล์) สำหรับหน้าส่วนใหญ่ถือว่าเหลือเฟือ แต่หน้าที่มีผู้เข้าชมมากและเพิ่มฟอนต์จะชนขีดจำกัดรายวันเร็วขึ้น จึงแนะนำให้เพิ่มไม่เกินหนึ่งฟอนต์สำหรับหัวข้อ ถ้าคุณดูแลโค้ดของ FluxBio ด้วย AI ที่แก้โค้ดได้อย่าง Claude Code ก็ลดการใช้ลงได้อีก (วิธีอยู่ใน AGENTS.md)

<details>
<summary><b>ข้อมูลเก็บไว้ที่ไหน?</b></summary>

ทั้งหมดอยู่ในบัญชี Cloudflare ของคุณ: หน้าเพจ ลิงก์สั้น และสถิติอยู่ใน D1 ส่วนรูปภาพอยู่ใน KV ไม่มีเซิร์ฟเวอร์กลาง ผู้พัฒนามองไม่เห็นข้อมูลของคุณ หน้าที่เผยแพร่แล้วและลิงก์สั้นเป็นสาธารณะ ฉบับร่างเห็นได้เฉพาะคุณและคนที่มีลิงก์ตัวอย่าง ส่วนสถิติและแดชบอร์ดต้องเข้าสู่ระบบก่อน

</details>

<details>
<summary><b>รหัสผ่านแดชบอร์ด API token และคีย์ Cloudflare ต่างกันอย่างไร?</b></summary>

**รหัสผ่านแดชบอร์ด**ใช้เข้าสู่ระบบแดชบอร์ด ระบบสร้างให้ตอนดีพลอยและเปลี่ยนได้ทุกเมื่อ **API token** มีไว้ให้ AI และเครื่องมือต่าง ๆ: สร้างแยกให้ AI แต่ละตัว จะให้สิทธิ์แค่ “สร้างลิงก์สั้น” ก็ได้ และเพิกถอนทีละอันได้โดยไม่กระทบตัวอื่น **ข้อมูลรับรอง Cloudflare** ใช้กับสิ่งที่ทำได้เฉพาะที่ Cloudflare เช่น ดีพลอยหรือเชื่อมต่อโดเมน ควบคุมได้ทั้งบัญชี Cloudflare จึงไม่ควรวางลงในแชต

</details>

<details>
<summary><b>ถ้า token หลุดไปต้องทำอย่างไร?</b></summary>

เพิกถอน token นั้นใน “ตั้งค่า” แล้วสร้างอันใหม่ ถ้ารหัสผ่านแดชบอร์ดหลุด ให้ AI ช่วยเปลี่ยนรหัสผ่าน เมื่อเปลี่ยนแล้วทุกคนต้องเข้าสู่ระบบใหม่ และ token ทั้งหมดจะใช้ไม่ได้อีก

</details>

<details>
<summary><b>ถ้า AI แก้ผิดล่ะ?</b></summary>

การแก้ไขหน้าจะเก็บเป็นฉบับร่าง ผู้เข้าชมจะไม่เห็นอะไรจนกว่าจะเผยแพร่ ส่วนการตั้งค่าและลิงก์สั้นแบบเดี่ยวจะเปลี่ยนทันที คู่มือของ FluxBio บอกให้ AI ของคุณอธิบายว่าจะเปลี่ยนอะไรและถามคุณก่อน ถามว่าจะเผยแพร่เลยหรือดูตัวอย่างก่อน และสำรองข้อมูลก่อนเริ่ม ถ้าเกิดปัญหา AI ย้อนกลับไปใช้เวอร์ชันที่เผยแพร่ล่าสุดของหน้าได้ 1 ใน 20 ครั้ง หรือกู้คืนจากข้อมูลสำรอง เครื่องมือที่ไม่อ่านคู่มือจะไม่ทำตามนี้ ดังนั้นให้สิทธิ์เต็มเฉพาะ AI ที่คุณไว้ใจ

</details>

<details>
<summary><b>ไม่มี AI ใช้ได้ไหม?</b></summary>

ได้ การแก้หน้า รูปลักษณ์ ลิงก์สั้น QR Code สถิติ และการดาวน์โหลดข้อมูลสำรอง อยู่ในแดชบอร์ดทั้งหมด ส่วนการตั้งค่าอย่างโดเมน เขตเวลา และรูปลักษณ์ที่ใช้สีและรูปของคุณเองไม่มีหน้าจอให้ ต้องแก้ผ่าน API ดูคำอธิบายได้ที่ `/llms.txt` ของ FluxBio แต่ละชุด

</details>

<details>
<summary><b>รองรับ AI ตัวไหนบ้าง?</b></summary>

สำหรับการดีพลอย: เราแนะนำ Claude Code บนคอมพิวเตอร์ของคุณเอง แต่เครื่องมือเขียนโค้ดอื่นที่รันคำสั่งและต่ออินเทอร์เน็ตได้ก็ใช้ได้ เช่น Codex, OpenCode, Cursor, Cline, Roo Code, Kilo Code, Droid, Crush, Goose, Pi, TRAE, Qoder, ZCode, Eigent, Gemini CLI, GitHub Copilot, Windsurf สำหรับการดูแลประจำวัน: ใช้เครื่องมือเหล่านี้ หรือเครื่องมือที่เรียก API ได้ เช่น แอป Claude, Claude Cowork, ChatGPT (GPT ที่สร้างเอง), n8n “ตั้งค่า” ในแดชบอร์ดมีพรอมต์ให้วางลงใน Claude Code, Codex หรือ Cursor ส่วนเครื่องมืออื่นให้ชี้ไปที่ /llms.txt ของเว็บไซต์คุณ

</details>

<details>
<summary><b>จะเปลี่ยนโดเมน เปลี่ยนรหัสผ่าน หรือย้ายเว็บไซต์ได้อย่างไร?</b></summary>

บอก AI ได้เลย เช่น “เปลี่ยนโดเมนเป็น links.example.com” “ช่วยเปลี่ยนรหัสผ่านแดชบอร์ดให้หน่อย” หรือ “ย้ายเว็บไซต์ไปที่ FluxBio อีกชุด” โดเมนต้องเชื่อมกับ Worker นี้ใน Cloudflare ก่อน แล้ว AI จะพาคุณทำทีละขั้น

</details>

<details>
<summary><b>มีการติดตามผู้เข้าชมไหม?</b></summary>

FluxBio ไม่ใช้คุกกี้ และไม่เก็บ IP หรือสตริง User-Agent แบบเต็ม ในแต่ละการเข้าชมจะเก็บเวลา ที่มาของผู้เข้าชม อุปกรณ์ เบราว์เซอร์ ภาษา เครือข่าย และตำแหน่งโดยประมาณ (ละเอียดที่สุดราว 10 กม.) ไว้ 90 วัน พร้อมแฮชทางเดียวที่เปลี่ยนทุกวัน ส่วนยอดรวมเก็บไว้ตลอด บอตที่รู้จักและการพรีวิวลิงก์ไม่นับ มีสองอย่างที่ไปถึง Google: ฟอนต์โหลดจาก Google Fonts เว้นแต่คุณปิดไว้ใน “รูปลักษณ์” และหน้าที่มีวิดีโอ YouTube จะโหลดภาพขนาดย่อจากที่นั่น

</details>

## พัฒนา

```sh
cp .dev.vars.example .dev.vars   # ตั้ง ADMIN_PASSWORD สำหรับรันบนเครื่อง
pnpm dev                         # http://localhost:5173 แดชบอร์ดอยู่ที่ /admin/
pnpm test                        # รันเทสต์ใน Workers runtime
pnpm typecheck
```
