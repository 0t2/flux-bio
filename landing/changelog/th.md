# Changelog

What changed in FluxBio, a release at a time, newest first. fluxbio.link shows this file at `/en/changelog/` and is made from it.
If you host your own, `pnpm update:code` in your FluxBio folder brings its code to the newest release and shows the releases in between: read them before you deploy. Your site says which version it runs, in `version` of `GET /api/state` and at the top of `/llms.txt`. The number says what updating takes: a release that changes the middle number (0.3.4 to 0.4.0) has an "Action needed", and one that changes only the last (0.3.4 to 0.3.5) needs nothing but the deploy.

The format is narrow because a script reads it: `## <version> - YYYY-MM-DD` (newest first), then `### ` and one of Action needed, Security, New, Changed, Fixed (in that order), then `- ` entries on one line each, with only `code` and `[links](https://…)` as markup. `tests/changelog.test.ts` holds it. A change someone using FluxBio would see gets a release of its own, on top, in the same pull request, with its version in `package.json` too: the next minor if it has an Action needed, else the next patch. Leave purely internal work out. The date is the day the change reaches `main`. The headings below 0.3.0 are days without a version, because every site of those days called itself 0.2.1.

## 0.4.10 - 2026-11-20

### เปลี่ยนแปลง
- การลองรหัสผ่านของลิงก์ผิดจะนับแยกตามผู้เข้าชมแต่ละคน ลองผิดสิบครั้งใน 15 นาทีจะล็อกเฉพาะคนที่ลองผิด ไม่กระทบคนอื่น ตัวลิงก์เองยังมีจำนวนรวมของทุกคนที่ห้าสิบครั้ง ระบบแยกผู้เข้าชมด้วยอักขระแปดตัวที่สร้างจากที่อยู่ร่วมกับ salt ที่เปลี่ยนทุกวัน โดยไม่เก็บที่อยู่นั้นไว้ [#59](https://github.com/0t2/flux-bio/pull/59)

## 0.4.9 - 2026-11-20

### ความปลอดภัย
- รหัสประจำวันของผู้เข้าชมในสถิติแบบละเอียดใช้ค่าสุ่มที่เปลี่ยนทุกวันเป็น salt แทนรหัสผ่านผู้ดูแล การรู้รหัสผ่านจึงใช้ตรวจสอบไม่ได้อีกว่าที่อยู่ใดเคยเข้าชม จำนวนผู้เข้าชมของวันจะสูงเกินจริงในวันที่อัปเดตนี้ [#58](https://github.com/0t2/flux-bio/pull/58)

### แก้ไข
- การเผยแพร่ในขณะที่คนอื่นบันทึกฉบับร่าง ตอนนี้จะตอบกลับด้วยเวอร์ชันจริงของฉบับร่างและแจ้งว่าฉบับร่างถูกเก็บไว้ (`draftKept`) แดชบอร์ดจะใช้ฉบับร่างนั้นหรือถามว่าจะเก็บฉบับใด [#58](https://github.com/0t2/flux-bio/pull/58)
- หน้าที่เผยแพร่ในจังหวะเดียวกับที่ถูกย้าย ลิงก์ในหน้าได้ที่อยู่สั้นใหม่ หรือการเปลี่ยนการตั้งค่ากำลังคัดลอกฟอนต์ จะไม่เหลือสำเนาเก่า ที่อยู่สั้นที่ค้างอยู่ หรือไฟล์ฟอนต์ที่ผิดอีกต่อไป [#58](https://github.com/0t2/flux-bio/pull/58)
- การดาวน์โหลดสถิติในขณะที่ข้อมูลรายวันเก่าถูกรวมเป็นรายเดือนจะไม่ทำให้ตัวเลขตกหล่นจากไฟล์อีก การดาวน์โหลดจะได้รับแจ้งและเริ่มใหม่ตั้งแต่ต้น [#58](https://github.com/0t2/flux-bio/pull/58)

## 0.4.8 - 2026-11-20

- การเปลี่ยนการตั้งค่าบนเว็บไซต์ขนาดใหญ่อาจเริ่มงานมากกว่าที่คำขอเดียวได้รับอนุญาต แล้วล้มเหลว [#57](https://github.com/0t2/flux-bio/pull/57)

- การเปลี่ยนการตั้งค่าที่บันทึกแล้วแต่ยังไปไม่ถึงผู้เข้าชม จะถูกส่งเมื่อเปิดแดชบอร์ดครั้งถัดไป โดยไม่ต้องบันทึกซ้ำ [#56](https://github.com/0t2/flux-bio/pull/56)

## 0.4.6 - 2026-11-20

### ความปลอดภัย
- ลิงก์ดูตัวอย่างของฉบับร่างจะไม่แสดงที่อยู่ของลิงก์ที่มีรหัสผ่านหรือที่ซ่อนที่อยู่ไว้อีกต่อไป ปุ่มลักษณะนี้จะผ่านลิงก์สั้นในหน้าตัวอย่างเช่นเดียวกับในหน้าที่เผยแพร่แล้ว [#55](https://github.com/0t2/flux-bio/pull/55)
- รหัสผ่านของลิงก์รับการลองผิดได้สิบครั้งใน 15 นาที จากนั้นจะไม่รับอีกจนกว่าจะครบเวลา ก่อนหน้านี้ไม่มีการจำกัด [#55](https://github.com/0t2/flux-bio/pull/55)
- ที่อยู่ที่ไม่มีอยู่จริงจะไม่ใช้ทรัพยากรมากขึ้นตามความยาวอีกต่อไป การค้นหาที่อยู่ที่ใกล้เคียงอาจใช้เวลาหลายเท่าของขีดจำกัดเวลาต่อคำขอบนเว็บไซต์ขนาดใหญ่ และใครก็ส่งที่อยู่แบบนั้นได้ [#55](https://github.com/0t2/flux-bio/pull/55)

- การกู้คืนข้อมูลสำรองจะไม่ทำให้ลิงก์ที่ข้อมูลสำรองเก็บถาวรไว้ยังคงเปลี่ยนเส้นทางต่อไป [#55](https://github.com/0t2/flux-bio/pull/55)
- การตั้งค่าที่บันทึกในขณะที่อย่างอื่นกำลังบันทึกจะไม่ถูกเขียนทับ และการเปลี่ยนแปลงที่ไปถึงฐานข้อมูลแต่ไม่ถึงผู้เข้าชมจะถูกส่งไปเมื่อคุณทำซ้ำอีกครั้ง [#55](https://github.com/0t2/flux-bio/pull/55)
- รายการสองรายการที่มี id เดียวกันในหน้าเดียวจะถูกปฏิเสธเมื่อเผยแพร่ เพราะลิงก์สั้นของรายการหนึ่งจะใช้ไม่ได้ [#55](https://github.com/0t2/flux-bio/pull/55)

## 0.4.5 - 2026-11-20

### แก้ไข
- คู่มือที่เว็บไซต์ทดสอบหรือสำเนาในเครื่องให้บริการจะไม่ให้คำสั่งของเว็บไซต์จริงอีกต่อไป: คำสั่ง deploy จะมี `--mode staging` และคู่มือจะไม่บอกให้ AI ของคุณบันทึกคู่มือนั้นเป็น skill ของเว็บไซต์จริงอีก [#52](https://github.com/0t2/flux-bio/pull/52)
- ใน Worker ที่มีมากกว่าหนึ่งเว็บไซต์ หัวข้อ “ลบ FluxBio” ในคู่มือจะไม่ทำให้ AI ของคุณลบ Worker ทั้งหมดและฐานข้อมูลของเว็บไซต์แรกเพียงเพื่อนำเว็บไซต์เดียวออก [#52](https://github.com/0t2/flux-bio/pull/52)
- `pnpm run deploy` จะยึดตามเวอร์ชันของ Worker ที่กำลังทำงานอยู่จริง ซึ่งอาจไม่ใช่เวอร์ชันล่าสุดหลังจากย้อนกลับในแดชบอร์ดของ Cloudflare `pnpm deploy:images` จะอ่านรูปภาพของเว็บไซต์ที่สองด้วย token ของเว็บไซต์นั้นเอง และ `pnpm reset-password --mode staging` จะไม่แตะต้อง token ของเว็บไซต์จริงที่บันทึกไว้ [#52](https://github.com/0t2/flux-bio/pull/52)
- การรันเว็บไซต์ทดสอบบนคอมพิวเตอร์ของคุณ (`cf dev --mode staging`) ไม่ต้องลงชื่อเข้าใช้ Cloudflare อีกต่อไป [#52](https://github.com/0t2/flux-bio/pull/52)
- `GET /api/update` จะตอบว่าไม่ทราบ (`latest` เป็น null) เมื่อเจอเวอร์ชันหรือบันทึกการเปลี่ยนแปลงที่จัดลำดับไม่ได้ แทนที่จะบอกว่าเป็นเวอร์ชันล่าสุดแล้ว [#52](https://github.com/0t2/flux-bio/pull/52)

## 0.4.4 - 2026-11-20

### แก้ไข
- `pnpm reset-password` จะตรวจก่อนว่าที่อยู่ที่คุณระบุให้บริการโดย Worker ที่โฟลเดอร์ของคุณ deploy จริง แล้วจึงเปลี่ยนแปลง ก่อนหน้านี้ หากรันด้วยที่อยู่ของเว็บไซต์ทดสอบหรือเว็บไซต์ในเครื่องตามที่หน้าเข้าสู่ระบบแสดงไว้ คำสั่งจะเปลี่ยนรหัสผ่านของเว็บไซต์จริง นอกจากนี้ยังดึงรายการเว็บไซต์จาก Worker ที่ทำงานอยู่ บันทึกรหัสผ่านก่อนตั้งค่า และบอกว่าเว็บไซต์ใดไม่ได้รับ token [#51](https://github.com/0t2/flux-bio/pull/51)
- `pnpm run deploy` จะดู Worker ทั้งหมดในบัญชีก่อนสร้างเว็บไซต์ใหม่ ก่อนหน้านี้เห็นเพียงสิบรายการแรก FluxBio ที่อยู่ถัดลงไปในรายการจึงถูกมองข้าม คำสั่งจะหยุดเมื่ออ่าน Worker ใดไม่ได้ และจะไม่สร้างเว็บไซต์ทดสอบให้เว็บไซต์จริงที่ไม่มีอยู่อีกต่อไป [#51](https://github.com/0t2/flux-bio/pull/51)
- `pnpm update:code` จะไม่เขียนทับไฟล์ของคุณเองเมื่อรุ่นใหม่เริ่มใช้ชื่อเดียวกัน ไม่ทำให้ไฟล์ที่เปลี่ยนเฉพาะตัวพิมพ์เล็กใหญ่หายไป และไม่หยุดกลางคันเมื่อไฟล์กลายเป็นโฟลเดอร์ [#51](https://github.com/0t2/flux-bio/pull/51)
- `worker.json` รับชื่อ Worker ทุกแบบที่ Cloudflare รับ ใช้ขีดล่างได้และยาวได้ถึง 63 ตัวอักษร [#51](https://github.com/0t2/flux-bio/pull/51)

## 0.4.0 - 2026-11-20

### ต้องดำเนินการ
- หากคุณเคยแก้ `cloudflare.config.ts` (เปลี่ยน `WORKER_NAME` เพิ่มโดเมนของตัวเอง หรือเอา `ANALYTICS` ออก) ให้ย้ายการตั้งค่านั้นไปไว้ใน `worker.json` ในโฟลเดอร์ FluxBio ของคุณก่อน deploy เวอร์ชันนี้ เช่น `{ "name": "my-links", "domains": ["links.example.com"], "analytics": false }` ไฟล์นี้ไม่ใช่ส่วนหนึ่งของโค้ด การอัปเดตครั้งต่อไปจึงไม่แตะต้องมัน หากลืม การ deploy จะหยุดและบอกชื่อที่ต้องเขียน [#45](https://github.com/0t2/flux-bio/pull/45)

### ใหม่
- `pnpm run deploy` จะถาม Cloudflare ว่ามีอะไรทำงานอยู่ก่อนอัปโหลด และหยุดการ deploy ที่จะสร้างเว็บไซต์เปล่าอีกแห่ง ทำให้เว็บไซต์ของคุณแห่งหนึ่งออฟไลน์ เขียนทับ Worker อื่น หรือเปลี่ยนรหัสผ่านของคุณ ใช้คำสั่งนี้แทน `cf deploy` [#45](https://github.com/0t2/flux-bio/pull/45)
- `pnpm reset-password` ตั้งรหัสผ่านผู้ดูแลใหม่และสร้าง API token ใหม่ให้แต่ละเว็บไซต์ของคุณ โดยไม่แสดงทั้งสองอย่างบนหน้าจอ “ลืมรหัสผ่าน?” ในหน้าเข้าสู่ระบบตอนนี้ให้คำสั่งนี้ [#45](https://github.com/0t2/flux-bio/pull/45)
